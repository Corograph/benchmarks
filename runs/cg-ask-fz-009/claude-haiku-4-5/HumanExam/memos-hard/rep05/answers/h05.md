Mechanism — Database-level rule (explicit Go code triggers cascading SQL DELETE); Evidence locations — store/db/mysql/user_delete.go:438, store/db/postgres/user_delete.go:401, store/db/sqlite/user_delete.go:401

When a user is deleted, the Go code in each driver's `DeleteUser` method executes SQL statements that delete reactions WHERE `creator_id = <userID>`. For example, in MySQL: `DELETE FROM reaction WHERE creator_id = ?` (store/db/mysql/user_delete.go:438). This is explicit Go code that issues the deletion, not a database-level foreign-key rule, though it happens transactionally within the delete operation.
