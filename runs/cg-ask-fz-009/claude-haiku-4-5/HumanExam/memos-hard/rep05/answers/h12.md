Concrete method — sqlite.DB.CreateMemo (or mysql.DB.CreateMemo / postgres.DB.CreateMemo depending on driver); path — store/db/sqlite/memo.go (driver-specific); Determination method — Profile-based factory selection

With default installation (SQLite), `server.Server.NewServer()` constructs a store using `db.NewDBDriver()` (cmd/memos/main.go:57), which selects based on `profile.Driver`. Default is SQLite. When a memo is created, `APIV1Service.CreateMemo()` (server/router/api/v1/memo_service.go:70) calls `s.Store.CreateMemo()`, which dispatches to the concrete driver implementation determined at initialization (e.g., sqlite.DB.CreateMemo for SQLite).
